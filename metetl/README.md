# Инструкция MetETL

Программа помогает скачивать и обрабатывать картины из музея Метрополитен.

### Как запускать

Всегда пишите команду в терминале из папки проекта, начиная с python -m metetl ...

#### 1. Подготовка списка картин

Создает файл со списком картин для скачивания.

python -m metetl prepare --csv data/MetObjects.csv

#### 2. Скачивание и обработка

Скачивает картины и применяет к ним фильтры (размытие, контуры и т.д.).

* --num - сколько картин скачать (обязательно).

python -m metetl process --input data/to_download.json --num 3

#### 3. Анализ данных

Строит графики по имеющимся данным.

python -m metetl analyze --csv data/MetObjects.csv
